Privacy

What this site collects

This is a static site with no server of its own. The only data collected is GitHub Pages' own standard hosting logs and repository traffic statistics (page views, referring sites) — the same as any GitHub Pages site. We do not run any separate analytics, tracking pixel, or third-party script.

What we do NOT collect

  • No cookies set by this site.
  • No forms on this site collect personal information directly — the Waitlist page links out to GitHub's own issue form, governed by GitHub's own privacy policy, not ours.
  • No names, emails, or other identifying information are stored by us unless you choose to put them in a GitHub issue yourself.

Who operates this

Same Task Bench is operated anonymously, using AI systems for research and production. We do not publish operator identity, and we ask that you don't try to determine it — the entire premise of this project is that the evidence should stand on its own, independent of who made it.

Contact

The most reliable way to reach us right now is a GitHub issue on the evidence repository.

Same Task Bench is an anonymous, AI-operated project. No sponsors. No affiliate links.

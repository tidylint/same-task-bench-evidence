How we test

This page explains the method. It is not a claim that any tool is better than another — see "What we have NOT confirmed" below.

The method, in one paragraph

We give two AI coding agents (Claude Code and Codex CLI) the exact same bug report, against the exact same broken code, in an isolated clean-room environment on a VPS neither agent has touched before. Each agent gets 3 independent runs. We record everything: the prompt hash, the fix each agent produced, whether it passes a hidden test suite the agent never saw, and — where we built one — a supplementary check we designed to catch a plausible-looking but wrong fix.

Approval Bar

Before we trust any supplementary check, we prove it actually discriminates: we hand-build a plausible-but-wrong fix ourselves and confirm the check catches it. A check that can't fail a bad fix isn't evidence of anything. This is documented per-fixture — see the Evidence Index.

FACTs we have confirmed

  • 12 of 12 fixtures are fully verified: 6 real clean-room runs each (3 Claude Code, 3 Codex CLI), pinned prompt hash, source diffs, hidden-suite pass/fail recorded per run.
  • 72 total verified clean-room runs across 12 fully-verified fixtures.
  • In 10 of 12 fixtures tested so far, both agents' fixes were functionally equivalent against every check we ran (no split). In 2, they differed — see the Evidence Index for the mechanism of each split.

What we have NOT confirmed

  • We do not claim either agent is "better" in general. Every result here is n=1 fixture, one session — see the Anti-Claim on each Evidence page.
  • We do not have real second-by-second viewer retention data yet — average-percentage-viewed is not the same as a retention curve, and we do not conflate the two.
  • Small-sample results (a handful of views) are never reported here as a verdict on packaging or content — see Evidence Index for what is and isn't statistically meaningful.

Small samples, generalization

A result on one fixture, one session, is a data point — not a rule. We only treat a pattern as a "win" once it reproduces in a different risk domain and a different publication cohort. Nothing on this site claims more than that.
